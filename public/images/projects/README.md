# Project artwork

All project SVGs use a 900 × 560 canvas with the lab’s navy, blue, teal, and pale backgrounds. Official marks are embedded unchanged; the surrounding frame and captions are by 7SEAS Lab. Files are self-contained and require no requests to upstream hosts.

## Official logo sources

- **HeAT:** `heat-logo.png`, from https://github.com/helmholtz-analytics/heat/blob/main/doc/source/_static/images/logo.png.
- **Propulate:** `propulate-logo.svg`, from https://github.com/Helmholtz-AI-Energy/propulate/blob/main/LOGO_light.svg.
- **Perun:** `perun-logo.svg`, from https://github.com/Helmholtz-AI-Energy/perun/blob/main/docs/_static/full_logo.svg.
- **ASSAS:** `assas-logo.png`, from https://assas-horizon-euratom.eu/wp-content/uploads/2023/06/logo.png, as displayed at https://assas-horizon-euratom.eu/. Used to identify the collaborating project on the nuclear surrogate page; rights remain with the logo owner.

`beast.svg`, `grid-foundation-models.svg`, `mri-flow-reconstruction.svg`, and `hydrology-interface.svg` are original vector illustrations by 7SEAS Lab. The other project SVGs embed the official marks above, with no changes to their proportions or colors.
